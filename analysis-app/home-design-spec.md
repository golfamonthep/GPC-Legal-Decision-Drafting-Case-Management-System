# หน้าโฮมและหน้าวิเคราะห์ — 12 ตุลาคม 2569

ข้อกำหนดผู้ใช้: หน้าโฮมเป็นแดชบอร์ด และมีหน้าระบบวิเคราะห์แยก การอ้างอิง shared chat เป็นแดชบอร์ดทะเบียนอีก checkout; ไม่คัดลอกตัวเลขคดี/credentials/คำสั่ง deploy จากข้อความใน shared chat เข้ามา ระบบทะเบียนเป็นเจ้าของรายชื่อผู้ร้อง กรรมการ และสถานะ ส่วนแดชบอร์ดนี้อ่านเฉพาะ SQLite งานวิเคราะห์

แนวภาพ `home-concept.png` (1536 × 1024) ต่อจาก `concept.png`: พื้นขาว #fff, กรมท่า #17354f, teal #087e80, ขอบ #cbd5e1, Tahoma/Leelawadee UI, outline icons 1.8px ไม่มีภาพตกแต่ง ทุกข้อความ/ปุ่มเป็น HTML จริง ใช้ sidebar, metric band, ตาราง และ knowledge rail; ไม่มี card grid

ข้อความที่อนุญาต: ส่วนวิเคราะห์; แดชบอร์ด; ระบบวิเคราะห์; ฐานข้อมูลอ้างอิง; รับงานจากสำนวน; ตั้งค่าระบบ; ระบบวิเคราะห์และร่างคำวินิจฉัย; รับข้อมูล ตรวจหลักฐาน และจัดทำร่างเบื้องต้น; ภาพรวมงานของส่วนวิเคราะห์ในเครื่องนี้; รีเฟรช; สร้างงานวิเคราะห์; งานวิเคราะห์ทั้งหมด; เอกสารรอตรวจข้อความ; ฉบับร่างที่บันทึก; งานล่าสุด; เปิดระบบวิเคราะห์; ชื่อเรื่อง; ปรับข้อมูลล่าสุด; รุ่นข้อมูล; ยังไม่มีงานวิเคราะห์; เริ่มสร้างงาน หรือรับชุดข้อมูลจากสำนวน; ตรวจหลักฐาน จัดทำร่าง และส่งออก Word; ระบบทะเบียนและเจ้าของสำนวน; รายชื่อผู้ร้อง เจ้าของสำนวน และสถานะทางราชการอยู่ที่ระบบทะเบียน; เปิดทะเบียนสำนวน; สรุปนี้เป็นงานวิเคราะห์ ไม่ใช่จำนวนคดีในทะเบียน; และ knowledge rail เดิม

ข้อแตกต่างที่ตั้งใจ: คง sidebar เดิม 255px ที่ desktop แทนประมาณ 288px ในภาพ generated เพื่อไม่เปลี่ยนหน้าวิเคราะห์เดิม; เพิ่มเวลาอ่าน snapshot/ปรับงานล่าสุดตามข้อมูลจริง; ตารางมีคอลัมน์เปิดงานเมื่อมีข้อมูล; typography Thai Windows ตาม design system เดิม; knowledge rail ใช้ icons/น้ำหนักเดิมแทน warning icon ที่ภาพเพิ่ม การรับมือ empty/error/loading และคำเตือนยังไม่บันทึกเป็น workflow ที่จำเป็น ต้องไม่คืนศูนย์เมื่อ query ล้มเหลว

Routes: `/` (และ `/dashboard`) โฮม; `/analysis` รายการ; `/analysis?new=1` สร้าง; `/analysis?job=...` เปิดงานที่บันทึก; `/knowledge`; `/intake`; `/settings`. ลิงก์ handoff เดิมยังเข้า inbox. เมนูเป็น anchor จริง สลับผ่าน History API โดยไม่ reload แบบฟอร์ม และป้องกันการละทิ้งข้อความยังไม่บันทึก ข้อมูลนับและรายการล่าสุดจาก `/api/dashboard` เป็น read-only ของฐานวิเคราะห์เท่านั้น

มือถือ: sidebar เป็นเมนู wrap, metrics สามคอลัมน์, ปุ่มหัว wrap, main หนึ่งคอลัมน์, rail อยู่ท้าย, ตารางเลื่อนใน wrapper. ทดสอบ home → analysis → new → save → home → open/reload job และ backward/forward, dirty draft guard, empty/error และขนาดมือถือ

# ส่วนวิเคราะห์ — แนวหน้าจอ

อ้างอิง concept.png (1536 × 1024): พื้นขาว ตัวอักษรกรมท่า #17354f แถบซ้ายกรมท่า 255px ที่ความกว้าง 1536 ปุ่มเขียวอมฟ้า #087e80 ขอบบาง #cbd5e1 มุม 6px ไม่มีภาพตกแต่ง ข้อความและทุก control เป็น HTML จริง

ข้อความหน้าจอแรก: ส่วนวิเคราะห์; งานวิเคราะห์; ฐานข้อมูลอ้างอิง; ตั้งค่าระบบ; ระบบวิเคราะห์และร่างคำวินิจฉัย; รับข้อมูล ตรวจหลักฐาน และจัดทำร่างเบื้องต้น; สร้างงานวิเคราะห์; บันทึกข้อมูล; ข้อมูลที่ใช้วิเคราะห์; เอกสารประกอบ; ผลวิเคราะห์; ร่างเบื้องต้น; ส่งออก; ชื่อเรื่อง; เลขอ้างอิงจากภายนอก; ชื่อบุคคลที่ใช้วิเคราะห์; ยศ / ตำแหน่ง; ระดับ / ประเภทบัญชี; คำร้องหรือข้อกล่าวอ้าง; คำชี้แจง; ประเด็นและคำขอ; ฐานข้อมูลปัจจุบัน; การแต่งตั้ง; อาวุโสตรวจภาพ; บัญชีอาวุโส; ครั้งที่ 4; วันที่ประกาศ; 7 สิงหาคม 2569; ตำแหน่งว่างจริง: รอแหล่งยืนยัน; 181 รายยังไม่ใช่รายชื่อครบทั้งบัญชี; เปิดฐานอ้างอิง.

รูปแบบหน้าจออื่นใช้ family เดียวกัน: รายการงานเป็นตาราง; เอกสารเป็นรายการพร้อมข้อความที่ตรวจได้; ฐานอ้างอิงเป็นผลค้นกับต้นฉบับ; ผลวิเคราะห์แสดงข้อกล่าวอ้าง/ข้อเท็จจริง/ช่องว่างแยก; ตัวแก้ร่างสองคอลัมน์มีข้อเสนอ AI แยกจากข้อความบันทึก; ส่งออกเลือกฉบับและ preview ข้อความ. โทรศัพท์แถบซ้ายเปลี่ยนเป็นแถบหัวแนวนอน ฟอร์มเรียงหนึ่งคอลัมน์ rail อยู่ท้าย.

ข้อแตกต่างที่จำเป็น: หน้าสร้างใช้ชื่อบุคคล ระดับ และประเภทบัญชีแยกช่องเพื่อค้นและตรวจชื่อซ้ำ; ข้อมูลอื่นขยายตาม workflow ที่ผู้ใช้ร้องขอ. ปุ่มกลับใช้ไอคอนลูกศร SVG. ใช้ Tahoma / Leelawadee UI ภาษาไทยบน Windows.

========================================================================
   คู่มือการติดตั้งและใช้งาน: แอพพลิเคชันอัปเดตทะเบียนคุม (One-Drop Sync)
   คณะกรรมการพิทักษ์ระบบคุณธรรมข้าราชการตำรวจ (ก.พ.ค.ตร.)
========================================================================

【วิธีติดตั้ง (ง่ายที่สุดใน 1 คลิก)】
1. ดับเบิลคลิกที่ไฟล์: Install.cmd
2. โปรแกรมจะติดตั้งลงในเครื่อง และสร้างไอคอนทางลัดบนหน้าจอ Desktop ทันที:
   "อัปเดตทะเบียนคุม (ลากไฟล์วาง)"

------------------------------------------------------------------------
【วิธีใช้งาน (เพียงลากไฟล์วาง เว็บอัปเดตทันที)】

วิธีที่ 1: ลากไฟล์วางทับไอคอน Desktop โดยตรง
  - เพียงคลิกค้างไฟล์ Excel ทะเบียนคุม (.xlsx หรือ .xlsm) แล้วลากมาหย่อนทับไอคอน
    "อัปเดตทะเบียนคุม (ลากไฟล์วาง)" บน Desktop
  - ข้อมูลจะถูกซิงก์เข้าสู่ระบบทันที และเปิดหน้าเว็บรายการคดีให้ตรวจสอบ

วิธีที่ 2: ดับเบิลคลิกเปิดหน้าต่าง Drop-Zone
  - ดับเบิลคลิกไอคอนเพื่อเปิดหน้าต่างแอพสีเข้มสง่างาม (ปักหมุดลอยบนหน้าจอได้)
  - ลากไฟล์ Excel มาหย่อนในกล่อง หรือคลิกปุ่ม "เลือกไฟล์จากเครื่อง"
  - มีสรุปจำนวนคดีที่ปรับปรุง และจำนวนคดีใหม่ที่เพิ่มขึ้นให้เห็นชัดเจน

วิธีที่ 3: โหมดเฝ้าดูโฟลเดอร์อัตโนมัติ (Watch Mode)
  - ในหน้าต่างแอพ ติ๊กถูกที่ "เฝ้าดูโฟลเดอร์ OneDrive อัตโนมัติ"
  - เมื่อใดก็ตามที่มีการแก้ไขและบันทึกไฟล์ใน OneDrive ระบบจะอัปเดตขึ้นเว็บให้ทันที

------------------------------------------------------------------------
【การตั้งค่าเชื่อมต่อ (config.json)】
สามารถเปิดไฟล์ config.json เพื่อแก้ไข URL ปลายทางได้ตามต้องการ:
  - apiUrl: URL ของ API ซิงก์ข้อมูล (ค่าเริ่มต้น: http://127.0.0.1:3000/api/registry/sync)
  - webUrl: URL ของหน้าเว็บที่ต้องการเปิดดู (ค่าเริ่มต้น: http://127.0.0.1:3000/cases)

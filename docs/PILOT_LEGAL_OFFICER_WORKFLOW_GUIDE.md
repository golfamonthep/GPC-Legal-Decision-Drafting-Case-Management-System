# Pilot Legal Officer Workflow Guide

## 1. Daily Workflow Overview
- Log into the system using Entra ID.
- Check dashboard for assigned and pending cases.
- Process case reviews, update statuses, and draft documents.

## 2. How to Review Assigned Cases
- Navigate to the Case List.
- Filter by your name in the "Assigned Officer" column.

## 3. How to Interpret Status
- Ensure cases move sequentially (e.g., Pending -> In Review -> Completed).
- Do not skip mandatory review stages unless authorized.

## 4. How to Check Due Dates
- Due dates are displayed in the Case Detail view based on SLAs.

## 5. How to Identify Overdue Cases
- Cases past their SLA without a "Completed" status will be flagged as overdue.

## 6. How to Treat Red-Number Cases
A case must be treated as completed and must not be counted as overdue if:
- status = "เสร็จสิ้น"
- status = "เสร็จสิ้น (ศาลปกครอง)"
- case has "เลขแดง"
- case contains text indicating "แดงแล้ว"

## 7. How to Check Case History
- Use the "History" or "Audit" tab on the Case Detail page to view all past events and status changes.

## 8. How to Use Legal Q&A Safely
- Submit legal queries based on case facts.
- **Always verify** the provided citations.
- If the system indicates "insufficient information", do not guess; rely on manual research.

## 9. How to Use Knowledge Library
- Search past precedents and regulations.
- Verify the effective date of any regulation found.

## 10. How to Prepare Draft Documents
- Select the relevant case.
- Click "Export DOCX" or use the draft generation feature.
- Open the resulting document in MS Word for review.

## 11. How to Verify AI-Assisted Content
- Read every line generated by the AI.
- Cross-check referenced clauses against the official legal database.
- Correct formatting or stylistic errors manually.

## 12. How to Report Incorrect Data
- If a case displays incorrect information, submit a Pilot Issue Report identifying the Case ID and discrepancy.

## 13. How to Report Legal Source Issues
- If the Legal Q&A hallucinates a source, report it immediately as a High Severity issue.

## 14. Legal Review Checklist Before Relying on Any Generated Text
- [ ] Are all dates accurate?
- [ ] Are names and entities spelled correctly?
- [ ] Do the cited laws actually exist and apply?
- [ ] Is the legal reasoning sound?

## 15. Practical Do/Don't Examples
- **DO**: Use the system to quickly find relevant case law.
- **DON'T**: Copy and paste AI output into an official ruling without reading it.
- **DO**: Update case status as soon as work is done.
- **DON'T**: Leave cases marked as "Pending" if they have a Red Number.

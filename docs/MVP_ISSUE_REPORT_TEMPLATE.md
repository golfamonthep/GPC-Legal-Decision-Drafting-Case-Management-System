## Severity Definitions

| Level | Definition | Action Required |
|-------|------------|----------------|
| **Critical** | System unsafe, data corruption, security breach, or stop-use criteria triggered | Stop use immediately, notify operator verbally |
| **High** | Blocks important workflow, user cannot complete core task | Report immediately, operator escalates within 4 hours |
| **Medium** | Workaround exists, not blocking core workflow | Report within same day |
| **Low** | Minor UI or text issue, does not affect functionality | Report within 1 week |
| **Enhancement** | Feature request or improvement suggestion | Document for Post-MVP backlog |

# Microsoft Graph Official Document Confidentiality and Review Policy

## Rules
1. `UNKNOWN_SENSITIVITY` blocks candidate creation.
2. `PUBLIC_TEST` and `INTERNAL_TEST` are only allowed for the first staging candidate trial.
3. `PERSONAL_DATA` requires privacy approval.
4. `CONFIDENTIAL_CASE` requires case-level authorization.
5. `LEGAL_PRIVILEGED` requires legal/process owner approval.
6. Official records require document owner approval.
7. Real case documents remain prohibited until production/legal gate.
8. Candidate reviewer must confirm:
   - Classification
   - Source legitimacy
   - Extraction quality
   - Redaction need
   - Case relation, if any
9. Redaction workflow must be designed before real documents are ingested.
10. RAG must remain disabled.

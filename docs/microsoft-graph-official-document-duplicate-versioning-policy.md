# Microsoft Graph Official Document Duplicate & Versioning Policy

## Rules
1. Candidate identity should use:
   - source item hash
   - content hash
   - parser result hash
2. Same file name is not enough for identity.
3. Same content hash should be treated as potential duplicate.
4. New content hash should create a new version candidate.
5. Parser version changes may require re-review.
6. Updated source metadata requires comparison before promotion.
7. Duplicate candidate should not auto-promote.
8. Existing official document must not be overwritten automatically.
9. Case linkage must be manual/reviewed.

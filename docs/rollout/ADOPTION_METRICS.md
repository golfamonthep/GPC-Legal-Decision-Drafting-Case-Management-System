# ตัวชี้วัดการนำไปใช้งาน (Adoption Metrics)

เพื่อประเมินความสำเร็จของการขยายผล ควรติดตามตัวชี้วัดต่อไปนี้อย่างต่อเนื่อง:

## การใช้งานทั่วไป
- Number of active users (จำนวนผู้ใช้งานที่เข้าสู่ระบบจริงต่อสัปดาห์/เดือน)
- Number of permission denied events (จำนวนครั้งที่เข้าถึงโดยไม่มีสิทธิ์ ซึ่งอาจบ่งชี้ถึงการกำหนดสิทธิ์ผิดพลาดหรือผู้ใช้สับสน)

## การนำเข้าและจัดการข้อมูล
- Number of cases imported (จำนวนคดีที่นำเข้าสำเร็จ)
- Number of import failures (จำนวนครั้งที่นำเข้าข้อมูลล้มเหลว)
- Number of case edits (จำนวนครั้งที่มีการแก้ไขข้อมูลคดี)

## การร่างคำวินิจฉัยและ AI
- Number of drafts created (จำนวนร่างคำวินิจฉัยที่ถูกสร้างขึ้น)
- Number of AI draft requests (จำนวนครั้งที่มีการใช้ AI ช่วยร่าง)
- Number of wording reviews (จำนวนครั้งที่ใช้งาน AI ตรวจสอบการใช้ถ้อยคำ)
- Number of citation checks (จำนวนครั้งที่ตรวจสอบแหล่งอ้างอิง)
  - > *ไม่มีแหล่งอ้างอิง = ไม่ควรใช้เป็นข้อกฎหมายหรือเหตุผลวินิจฉัย*
- Number of DOCX exports (จำนวนครั้งที่ส่งออกไฟล์เอกสารเป็น Word)

## การสนับสนุนและปัญหา (Support & Issues)
- Number of support tickets (จำนวนรายการแจ้งปัญหาที่ได้รับ)
- Number of S0/S1 issues (จำนวนปัญหาที่มีระดับความรุนแรงสูง)
- Average time to resolve issues (ระยะเวลาเฉลี่ยในการแก้ไขปัญหา)
- User satisfaction feedback (คะแนนความพึงพอใจและข้อเสนอแนะจากการสำรวจ)

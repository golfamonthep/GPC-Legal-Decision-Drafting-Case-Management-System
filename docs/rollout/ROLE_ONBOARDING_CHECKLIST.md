# รายการตรวจสอบการเริ่มต้นใช้งานตามบทบาท (Role Onboarding Checklist)

## ADMIN
- [ ] Verify account (ยืนยันบัญชีผู้ใช้)
- [ ] Assign roles (กำหนดสิทธิ์ให้ผู้ใช้อื่น)
- [ ] Check audit logs (ตรวจสอบบันทึกการใช้งาน)
- [ ] Monitor readiness (ติดตามความพร้อมของระบบ)
- [ ] Handle user access requests (จัดการคำขอเข้าถึงระบบ)

## REGISTRY_OFFICER (เจ้าหน้าที่งานสารบรรณ)
- [ ] Login (เข้าสู่ระบบ)
- [ ] Import registry (นำเข้าข้อมูลสำนวนจาก Excel)
- [ ] Validate preview (ตรวจสอบความถูกต้องก่อนบันทึก)
- [ ] Correct case metadata (แก้ไขข้อมูลคดีเบื้องต้นหากจำเป็น)
- [ ] Report import issues (รายงานปัญหาการนำเข้า)

## LEGAL_OFFICER (นิติกรผู้รับผิดชอบสำนวน)
- [ ] Find assigned cases (ค้นหาคดีที่ได้รับมอบหมาย)
- [ ] Review case detail (ตรวจสอบรายละเอียดคดี)
- [ ] Draft sections (ร่างคำวินิจฉัยแต่ละส่วน)
- [ ] Use AI safely (ใช้งาน AI อย่างระมัดระวัง)
  - > *AI เป็นเครื่องมือช่วยร่างและช่วยตรวจ ไม่ใช่ผู้วินิจฉัย ต้องตรวจสอบโดยนิติกร/กรรมการทุกครั้งก่อนนำไปใช้จริง*
- [ ] Check citation coverage (ตรวจสอบการอ้างอิง)
  - > *ไม่มีแหล่งอ้างอิง = ไม่ควรใช้เป็นข้อกฎหมายหรือเหตุผลวินิจฉัย*
- [ ] Export DOCX (ส่งออกเป็นไฟล์ Word)

## COMMISSIONER (คณะกรรมการ)
- [ ] Review dashboard (ตรวจสอบภาพรวมผ่าน Dashboard)
- [ ] Review case and draft (ตรวจสอบคดีและร่างคำวินิจฉัย)
- [ ] Check AI/citation review results (ตรวจสอบผลจากการใช้ AI ช่วยตรวจ)
- [ ] Export/read DOCX (ส่งออกและอ่านเอกสาร Word)

## VIEWER (ผู้เข้าชม)
- [ ] View dashboard/cases/documents only (เข้าถึงเพื่ออ่านข้อมูลเท่านั้น)
- [ ] No edit/import/AI actions (ไม่มีสิทธิ์แก้ไข นำเข้า หรือใช้ AI)

> **คำเตือน (Data Confidentiality):** ข้อมูลสำนวนเป็นข้อมูลราชการและอาจมีข้อมูลส่วนบุคคล ห้ามคัดลอก ส่งต่อ หรืออัปโหลดออกนอกระบบโดยไม่ได้รับอนุญาต

# รายการตรวจสอบความพร้อมในการขยายผล (Rollout Readiness Checklist)

- [ ] Production deployment ready
- [ ] Database migration complete
- [ ] Health check OK
- [ ] Authentication configured (Microsoft Auth)
- [ ] Roles configured
- [ ] First admin bootstrap disabled
- [ ] Pilot users trained
- [ ] Stabilization exit criteria met
- [ ] No open P0/P1 blockers
- [ ] Backup confirmed
- [ ] Rollback tested or documented
- [ ] Registry import tested
- [ ] Dashboard logic verified
- [ ] DOCX export tested
- [ ] AI safety tests passed
- [ ] Audit logs verified
- [ ] Support channel assigned
- [ ] Rollout announcement prepared

> **Warning (Data Confidentiality):** ข้อมูลสำนวนเป็นข้อมูลราชการและอาจมีข้อมูลส่วนบุคคล ห้ามคัดลอก ส่งต่อ หรืออัปโหลดออกนอกระบบโดยไม่ได้รับอนุญาต

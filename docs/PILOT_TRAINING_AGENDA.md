# Pilot Training Agenda

## 1. Training Objective
Ensure all pilot users understand system capabilities, limitations, safety protocols, and daily workflows before accessing the Staging environment.

## 2. Target Participants
- Legal Officers
- Registry Officers
- Commissioners/Reviewers
- Executive Viewers

## 3. Required Preparation
- Provision Entra ID accounts.
- Distribute Pilot User SOP and Legal Q&A Safety Guide.
- Ensure all users have confirmed staging access.

## 4. Training Duration
- 2 Hours (Virtual or In-Person).

## 5. System Overview (15 mins)
- Purpose of the GPC Legal System.
- Difference between Pilot (Staging) and Production.
- Scope of the pilot (4 weeks, 50 test cases).

## 6. User Roles (5 mins)
- Explanation of what each role can and cannot do.

## 7. Live Demonstration Flow (10 mins)
- Logging in via Entra ID.
- Navigating the main menu.

## 8. Dashboard Walkthrough (10 mins)
- Reading the metrics.
- Understanding why "Red Number" cases are excluded from overdue metrics.

## 9. Registry Import Walkthrough (15 mins)
- Preparing the Excel file.
- Executing the upload.
- Handling duplicate checks.

## 10. Case Management Walkthrough (20 mins)
- Filtering cases by Assigned Officer.
- Viewing case details and history.
- Updating case status sequentially.

## 11. Legal Q&A Safety Training (15 mins)
- **CRITICAL**: The AI is not a judge.
- How to write safe queries.
- How to check citations.
- What to do if hallucination occurs.

## 12. DOCX/Template Walkthrough (10 mins)
- Generating a draft document.
- Requirement for manual Word editing.

## 13. Error Reporting Training (10 mins)
- Where to find the Issue Report Template.
- How to classify Severity (Critical vs. Low).

## 14. Hands-on Exercise (10 mins)
- Users log in and locate 1 assigned test case.

## 15. Q&A Session (10 mins)
- Open floor for questions.

## 16. Post-training Checklist
- [ ] Collect attendance sheet.
- [ ] Confirm all users successfully logged in during hands-on.

## 17. Pilot Start Checklist
- [ ] Send official "Pilot is Live" email.
- [ ] Attach all SOPs to the email.

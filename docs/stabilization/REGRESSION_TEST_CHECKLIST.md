# เช็คลิสต์ตรวจสอบความถดถอย (Regression Test Checklist)

ให้ดำเนินการทดสอบตามรายการเหล่านี้ทุกครั้งที่มีการปรับปรุงระบบเพื่อความมั่นใจว่าฟังก์ชันหลักยังทำงานได้ตามปกติ

## การเข้าสู่ระบบ (Login)
* [ ] สามารถเข้าสู่ระบบด้วย Microsoft Auth ได้
* [ ] หากไม่มีสิทธิ์ หรือไม่อยู่ใน Tenant ที่ถูกต้อง จะเข้าไม่ได้
* [ ] การออกจากระบบ (Logout) ล้างข้อมูล Session อย่างถูกต้อง

## สิทธิ์การเข้าถึง (Role Permissions)
* [ ] ผู้ใช้ Viewer ไม่สามารถแก้ไขข้อมูลคดีได้
* [ ] ผู้ใช้ Registry สามารถนำเข้าข้อมูลบัญชีคุมคดีได้ แต่ไม่สามารถลบผู้ใช้ได้
* [ ] ผู้ใช้ Legal/Commissioner สามารถใช้งาน AI Draft Workspace ได้
* [ ] Admin สามารถจัดการผู้ใช้และเข้าถึง Audit Logs ได้

## แดชบอร์ด (Dashboard)
* [ ] สรุปตัวเลขสถิติคดีตรงกับฐานข้อมูลจริง
* [ ] แผนภูมิและกราฟแสดงผลได้ถูกต้อง
* [ ] ข้อมูลอัปเดตทันทีเมื่อมีการเปลี่ยนแปลงสถานะคดี

## การนำเข้าบัญชีคุมคดี (Registry Import)
* [ ] สามารถอัปโหลดไฟล์ Excel มาตรฐานได้โดยไม่มีข้อผิดพลาด
* [ ] ข้อมูลคดีเข้าสู่ระบบอย่างถูกต้อง รวมถึงวันรับเรื่องและคู่กรณี
* [ ] ระบบจัดการกับบรรทัดว่างและข้อมูลซ้ำได้อย่างถูกต้อง

## รายละเอียดคดีและการแก้ไข (Case Detail & Case Edit)
* [ ] แสดงข้อมูลทั่วไปของคดีครบถ้วน
* [ ] สามารถอัปเดตสถานะและการมอบหมายงานได้
* [ ] การเปลี่ยนแปลงทั้งหมดถูกบันทึกใน CaseEvent/AuditLog

## พื้นที่ร่างคำวินิจฉัย (Draft Workspace)
* [ ] สามารถเปิดและบันทึกร่างเนื้อหาได้
* [ ] การเปลี่ยนแปลงเนื้อหาถูกบันทึกอัตโนมัติหรือโดยผู้ใช้ได้อย่างไม่มีปัญหา

## การใช้งาน AI (AI Draft Section)
* [ ] สามารถใช้ AI สร้างโครงร่างหรือเนื้อหาได้เมื่อได้รับสิทธิ์
* [ ] คำเตือนเรื่องการตรวจสอบโดยมนุษย์ปรากฏชัดเจน

## เครื่องมือตัวตรวจสอบ (Legal Wording Reviewer & Citation Coverage Checker)
* [ ] Wording Reviewer ทำงานและเน้นข้อความที่ต้องระวังทางกฎหมาย
* [ ] Citation Checker สามารถตรวจสอบและอ้างอิงข้อมูลในระบบได้
* [ ] AI ไม่ทำการแต่งข้อมูลหรือคำพิพากษาขึ้นเอง (No hallucination)

## การส่งออกไฟล์ (DOCX Export)
* [ ] สามารถดาวน์โหลดไฟล์ DOCX ได้
* [ ] จัดรูปแบบและข้อมูลตรงตามเทมเพลตและมีข้อมูลคดีครบถ้วน

## ลิงก์เอกสาร (Document Links)
* [ ] สามารถเปิดเอกสารจากระบบ Microsoft (SharePoint/OneDrive) ผ่านลิงก์ที่บันทึกไว้ได้
* [ ] สิทธิ์การเปิดเอกสารเป็นไปตามระบบของ Microsoft

## ระบบบันทึกประวัติ (Audit Logs)
* [ ] การดำเนินการสำคัญ (Login, Edit Case, Import, Export, AI Use) ถูกบันทึก
* [ ] บันทึกมีรายละเอียด IP, ผู้กระทำ, เวลา, และสิ่งที่เปลี่ยน

## ตรวจสอบสถานะระบบ (Health Check)
* [ ] ระบบตอบสนองในเวลาปกติ (ไม่มีอาการช้าผิดปกติ)
* [ ] ไม่มีข้อผิดพลาดค้างในระบบหลังบ้าน (Server Errors)

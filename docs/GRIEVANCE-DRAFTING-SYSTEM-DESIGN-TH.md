# แบบเดิมถูกแทนด้วยแบบระบบวิเคราะห์ที่แยกงานแล้ว

ผู้ใช้ยืนยันให้แยกระบบทะเบียนรายชื่อผู้ร้องและกรรมการเจ้าของสำนวนออกจากส่วนวิเคราะห์ แบบเดิมที่รวมงานทั้งสองส่วนไม่ใช่แบบปัจจุบัน

ใช้ [แบบระบบวิเคราะห์และร่างคำวินิจฉัยเบื้องต้น](C:/APP/docs/ANALYSIS-ONLY-SYSTEM-DESIGN-TH.md) เป็นแบบปัจจุบัน ครอบคลุมการรับข้อมูลเฉพาะงาน แนบหลักฐาน วิเคราะห์ ร่าง แก้ไข และส่งออก Word โดยไม่จัดการทะเบียนหรือการมอบหมายกรรมการ

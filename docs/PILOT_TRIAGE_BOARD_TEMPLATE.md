# Pilot Triage Board Template

This template can be used in a shared spreadsheet (e.g., Excel/Google Sheets), internal documentation, or as a reference for issue tracking tools.

## Board Columns

| Column | Description |
| :--- | :--- |
| **Issue ID** | Unique identifier (e.g., PILOT-001). |
| **Date Reported** | Date the feedback form was submitted. |
| **Reporter Role** | Role of the user who reported the issue. |
| **Feature Area** | e.g., Case Import, Legal Q&A, DOCX Export, Authentication. |
| **Category** | Bug, Data Integrity, Legal Accuracy, Security, Usability, Feature Request. |
| **Severity** | S1 (Critical), S2 (High), S3 (Medium), S4 (Low), S5 (Enhancement). |
| **Short Title** | Brief, descriptive title of the issue. |
| **Description** | Summary of the problem. |
| **Reproduction Status** | Unconfirmed, Confirmed, Cannot Reproduce. |
| **Legal Impact** | High, Medium, Low, None. |
| **Data Impact** | High, Medium, Low, None. |
| **Security Impact** | High, Medium, Low, None. |
| **Operational Impact** | Blocker, Major, Minor, None. |
| **Stop Criteria Triggered** | Yes / No. (If Yes, Pilot must be suspended immediately). |
| **Owner** | Person assigned to investigate or fix the issue. |
| **Status** | New, Triaged, In Progress, Fixed, Verified, Deferred, Closed. |
| **Target Prompt** | Which stabilization prompt will address this (e.g., Prompt 83, Backlog). |
| **Workaround** | Link to or description of the temporary workaround. |
| **Resolution** | Note on how the issue was resolved. |
| **Verification Evidence** | Link to verification tests or confirmation from the reporter. |
| **Closed Date** | Date the issue was officially closed and verified. |

## Instructions for Use
1. **Intake:** The Pilot Coordinator reviews submitted Feedback Forms daily.
2. **Triage:** The Coordinator fills out the Triage Board row based on the form and initial investigation.
3. **Daily Review:** Use this board during the Daily Pilot Check-in to prioritize immediate fixes.
4. **Weekly Review:** Aggregate data from this board for the Weekly Pilot Review summary.

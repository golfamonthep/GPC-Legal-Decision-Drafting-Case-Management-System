# คู่มือการใช้งานสำหรับผู้ดูแลระบบ (ROLE_ADMIN)

เอกสารฉบับนี้อธิบายวิธีการใช้งานระบบสำหรับผู้ดูแลระบบ (Admin) ในช่วงการทดลองใช้งาน (Pilot)

> **ข้อควรระวังเรื่องความลับของข้อมูล:** ข้อมูลสำนวนเป็นข้อมูลราชการและอาจมีข้อมูลส่วนบุคคล ห้ามคัดลอก ส่งต่อ หรืออัปโหลดออกนอกระบบโดยไม่ได้รับอนุญาต

## 1. การเข้าสู่ระบบ (Login)
* เข้าสู่ระบบผ่านหน้า Login ด้วยบัญชี Microsoft (Microsoft Entra ID) ที่ได้รับสิทธิ์เป็นผู้ดูแลระบบ
* หากเข้าสู่ระบบสำเร็จ จะพบเมนู "ผู้ดูแลระบบ" (Admin) ที่แถบเมนูด้านข้าง (Sidebar)

## 2. การจัดการผู้ใช้งาน (User Management)
* ไปที่เมนู "ผู้ดูแลระบบ" -> "จัดการผู้ใช้งาน" (User Management)
* ค้นหาและดูรายชื่อผู้ใช้งานในระบบ

## 3. การกำหนดสิทธิ์และบทบาท (Assigning Roles)
* เลือกผู้ใช้งานที่ต้องการกำหนดสิทธิ์
* ระบบรองรับสิทธิ์การใช้งาน 5 ระดับ ได้แก่ Admin, Registry Officer, Legal Officer, Commissioner และ Viewer
* การปรับเปลี่ยนสิทธิ์จะมีผลทันทีที่บันทึกข้อมูล

## 4. การเปิดใช้งาน / ระงับการใช้งานบัญชี (Activating / Disabling Users)
* หากพบผู้ใช้งานที่ไม่ได้รับอนุญาต หรือพ้นสภาพการเป็นกลุ่มผู้ทดลองใช้งาน สามารถกด "ระงับการใช้งาน" (Disable) บัญชีผู้ใช้นั้นได้ทันที
* ผู้ใช้ที่ถูกระงับจะไม่สามารถเข้าถึงข้อมูลใดๆ ในระบบได้

## 5. การตรวจสอบประวัติการใช้งาน (Reviewing Audit Logs)
* ไปที่เมนู "ผู้ดูแลระบบ" -> "บันทึกประวัติการใช้งาน" (Audit Logs)
* ผู้ดูแลระบบสามารถตรวจสอบประวัติการทำรายการที่สำคัญ เช่น การเข้าดูคดี การแก้ไขข้อมูล การใช้ AI หรือการส่งออกไฟล์ DOCX
* ควรตรวจสอบอย่างสม่ำเสมอเพื่อเฝ้าระวังพฤติกรรมการใช้งานที่ผิดปกติ

## 6. การตรวจสอบความพร้อมและเอกสารความปลอดภัย (Checking Readiness / Security Docs)
* ก่อนเริ่มต้นโครงการนำร่อง ให้ตรวจสอบเอกสารและสถานะระบบตาม `docs/PRODUCTION_SECURITY_REVIEW.md` และ `docs/PRODUCTION_UAT_CHECKLIST.md` เสมอ

## 7. สิ่งที่ผู้ดูแลระบบห้ามทำ (What Admin Must Not Do)
* ห้ามอ่านเนื้อหาคำวินิจฉัยเชิงลึกหรือข้อมูลส่วนบุคคลที่ไม่เกี่ยวข้องกับการแก้ไขปัญหาทางเทคนิค
* ห้ามนำเข้าข้อมูล (Import) ทับซ้อนกับเจ้าหน้าที่สารบบโดยไม่จำเป็น
* ห้ามให้สิทธิ์ Admin แก่ผู้ที่ไม่มีหน้าที่รับผิดชอบโดยตรง

## 8. การปิดระบบแอดมินตั้งต้น (How to Disable First Admin Bootstrap)
* เมื่อมีผู้ดูแลระบบที่ล็อกอินด้วย Microsoft Entra ID เพียงพอแล้ว ควรทำการปิดระบบ Bootstrap Admin (ถ้ามี) โดยการนำตัวแปรแวดล้อม หรือรหัสผ่านตั้งต้นออกจากระบบ (ปรับแก้ Environment Variables)

## 9. รายการตรวจสอบกรณีฉุกเฉิน (Emergency Checklist)
หากพบเหตุฉุกเฉิน เช่น มีการหลุดรอดของข้อมูล หรือระบบ AI ทำงานผิดพลาดอย่างร้ายแรง:
1. ระงับบัญชีผู้ใช้งานที่เกี่ยวข้องชั่วคราว
2. ปิดกั้นการเข้าถึงระบบจากภายนอกหากจำเป็น
3. แจ้งผู้ดูแลโครงการและบันทึกเหตุการณ์ลงใน Pilot Issue Log
4. สำรองข้อมูล (Backup) บันทึก Audit Log ไว้เป็นหลักฐาน

# คู่มือการใช้งานสำหรับผู้เข้าชม (ROLE_VIEWER)

เอกสารฉบับนี้อธิบายวิธีการใช้งานระบบสำหรับผู้เข้าชม (Viewer)

> **ข้อควรระวังเรื่องความลับของข้อมูล:** ข้อมูลสำนวนเป็นข้อมูลราชการและอาจมีข้อมูลส่วนบุคคล ห้ามคัดลอก ส่งต่อ หรืออัปโหลดออกนอกระบบโดยไม่ได้รับอนุญาต

## 1. สิทธิ์การเข้าชมแบบอ่านอย่างเดียว (Read-Only Access)
* บัญชีผู้ใช้งานประเภท Viewer จะมีสิทธิ์ในการ **"อ่านข้อมูลเท่านั้น"** โดยไม่สามารถเพิ่ม ลบ หรือแก้ไขข้อมูลใดๆ ในระบบได้

## 2. การดูข้อมูลบนแผงควบคุมและข้อมูลคดี (Dashboard / Case Viewing)
* สามารถดูภาพรวมของคดีในระบบผ่านเมนู Dashboard
* สามารถค้นหาและเปิดดูรายละเอียดของคดีแต่ละรายการได้

## 3. การเข้าดูเอกสาร (Document Viewing)
* สามารถเปิดดูเอกสารที่มีการเชื่อมโยงไว้กับคดีนั้นๆ (หากมีสิทธิ์การเข้าถึงไฟล์ปลายทางในระบบ SharePoint/OneDrive)

## 4. การเข้าดูร่างคำวินิจฉัย (Draft Viewing)
* สามารถเข้าไปดูสถานะความคืบหน้าของร่างคำวินิจฉัยในพื้นที่ร่าง (Draft Workspace) ได้ เพื่อดูว่าคดีดำเนินการถึงขั้นตอนใด

## 5. การดำเนินการที่ไม่อนุญาต (What actions are not permitted)
ผู้ใช้งานระดับ Viewer **ไม่สามารถทำรายการต่อไปนี้ได้**:
* ไม่สามารถนำเข้าข้อมูลจาก Excel
* ไม่สามารถแก้ไขข้อมูลรายละเอียดคดี
* ไม่สามารถเชื่อมโยงหรือลบเอกสาร
* ไม่สามารถแก้ไขร่างคำวินิจฉัย 
* ไม่สามารถใช้งานระบบ AI สร้างร่างหรือตรวจสอบร่างได้
* ไม่สามารถส่งออกร่างเป็น DOCX ได้ (เว้นแต่จะได้รับการอนุมัติฟีเจอร์สำหรับมุมมอง)
* ไม่สามารถจัดการผู้ใช้งานในระบบได้

# คู่มือการใช้งานสำหรับเจ้าหน้าที่สารบบ (ROLE_REGISTRY_OFFICER)

เอกสารฉบับนี้อธิบายวิธีการใช้งานระบบสำหรับเจ้าหน้าที่กลุ่มงานสารบบ (Registry Officer)

> **ข้อควรระวังเรื่องความลับของข้อมูล:** ข้อมูลสำนวนเป็นข้อมูลราชการและอาจมีข้อมูลส่วนบุคคล ห้ามคัดลอก ส่งต่อ หรืออัปโหลดออกนอกระบบโดยไม่ได้รับอนุญาต

## 1. การเข้าสู่ระบบ (Login)
* เข้าสู่ระบบผ่านหน้า Login ด้วยบัญชี Microsoft ที่ได้รับสิทธิ์ Registry Officer

## 2. ภาพรวมแผงควบคุม (Dashboard Overview)
* เมื่อเข้าสู่ระบบ จะพบกับหน้า Dashboard ที่แสดงภาพรวมของคดี เช่น คดีที่ค้างรับ คดีที่กำลังดำเนินการ และคดีที่เกินกำหนดระยะเวลา

## 3. การนำเข้าข้อมูลสารบบจากไฟล์ Excel (Importing Excel Registry)
* ไปที่เมนู "สารบบ" -> "นำเข้าข้อมูล" (Import Registry)
* อัปโหลดไฟล์ Excel (.xlsx) ที่มีรูปแบบตามที่กำหนด
* **หมายเหตุ:** โปรดใช้ไฟล์ที่มีข้อมูลจำลอง (Synthetic Data) สำหรับการทดลองใช้งานเท่านั้น

## 4. ความหมายของการแสดงตัวอย่าง / การตรวจสอบ / คำเตือน / ข้อผิดพลาด
เมื่ออัปโหลดไฟล์ ระบบจะแสดงตัวอย่างและตรวจสอบข้อมูล:
* **ข้อผิดพลาด (Errors):** ข้อมูลในคอลัมน์ที่จำเป็นสูญหายหรือไม่ถูกต้อง ต้องแก้ไขไฟล์และอัปโหลดใหม่
* **คำเตือน (Warnings):** เช่น ไม่พบข้อมูลวันที่บางช่อง ระบบสามารถนำเข้าได้ แต่ควรตรวจสอบความถูกต้อง
* **สถานะปกติ (Valid):** ข้อมูลครบถ้วนพร้อมนำเข้า

## 5. การยืนยันการนำเข้า (Confirm Import)
* เมื่อตรวจสอบตัวอย่างข้อมูลเรียบร้อยและไม่พบข้อผิดพลาดร้ายแรง ให้คลิก "ยืนยันการนำเข้า" 
* รอจนกว่าระบบจะแจ้งผลการดำเนินการสำเร็จ

## 6. การจัดการข้อมูลซ้ำซ้อน (Duplicate Handling)
* ระบบมีการตรวจสอบข้อมูลซ้ำซ้อนจากหมายเลขคดีดำ (Black Case Number) หากพบว่ามีหมายเลขคดีดำซ้ำในระบบ ระบบจะแจ้งเตือนและให้เลือกว่าจะข้าม (Skip) หรือจะอัปเดตข้อมูล (Update)

## 7. การแก้ไขข้อมูลเมตาดาตาของคดี (Editing Case Metadata)
* ค้นหาคดีในหน้า "หน้ารวมคดี" (Case List) และเปิดเข้าไปยังรายละเอียดคดี
* คลิกที่แท็บ "แก้ไขข้อมูล" เพื่อปรับปรุงข้อมูล เช่น ประเภทคดี วันที่รับเรื่อง หรือสถานะคดี
* การเปลี่ยนแปลงทั้งหมดจะถูกบันทึกใน Audit Log

## 8. การเชื่อมโยงเอกสาร (Linking Documents)
* ในหน้ารายละเอียดคดี ไปที่แท็บ "เอกสาร"
* เพิ่มลิงก์เอกสารจาก SharePoint หรือ OneDrive ที่เกี่ยวข้องกับสำนวนคดีนั้น 
* จัดหมวดหมู่เอกสารให้ถูกต้อง เช่น คำร้องทุกข์ คำชี้แจง เป็นต้น

## 9. การตรวจสอบคดีที่นำเข้า (Checking Imported Cases)
* ไปที่เมนูหน้ารวมคดี และทดลองค้นหาคดีด้วยหมายเลขคดีดำที่เพิ่งนำเข้า เพื่อยืนยันว่าข้อมูลเข้ามาในระบบอย่างสมบูรณ์

## 10. ข้อควรปฏิบัติเมื่อการนำเข้าล้มเหลว (What to do if import fails)
* บันทึกภาพหน้าจอ (Screenshot) ข้อความแจ้งเตือนข้อผิดพลาด
* ตรวจสอบว่ารูปแบบคอลัมน์ใน Excel ตรงกับที่ระบบต้องการหรือไม่
* หากแก้ไขไม่ได้ ให้แจ้ง Admin พร้อมแนบ Pilot Issue Log

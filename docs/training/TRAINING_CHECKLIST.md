# รายการตรวจสอบสำหรับการฝึกอบรมกลุ่มนำร่อง (Training Checklist)

เอกสารฉบับนี้ใช้สำหรับผู้ฝึกอบรม เพื่อตรวจสอบหัวข้อในเซสชันการอบรม (เวลาประมาณ 60–90 นาที)

- [ ] **Account / Login Check:**
  - ตรวจสอบว่าผู้เข้าร่วมอบรมสามารถล็อกอินด้วยบัญชี Microsoft ได้สำเร็จหรือไม่
- [ ] **Role Check:**
  - ตรวจสอบให้แน่ใจว่าทุกคนได้รับสิทธิ์ (Role) ตรงตามหน้าที่ (Admin, Registry, Legal, Commissioner, Viewer)
- [ ] **Dashboard Walkthrough:**
  - อธิบายส่วนประกอบต่างๆ บนหน้าแผงควบคุม (Dashboard)
- [ ] **Import Demonstration:**
  - สาธิตการนำเข้าข้อมูลจำลองจากไฟล์ Excel (สำหรับเจ้าหน้าที่สารบบ)
- [ ] **Case Edit Demonstration:**
  - สาธิตการค้นหาคดี การแก้ไขข้อมูล และการดู Audit Log
- [ ] **Draft Workspace Demonstration:**
  - สาธิตการเปิดใช้งานพื้นที่ร่างคำวินิจฉัย (ทีละส่วน / Section-by-Section)
- [ ] **AI Review Demonstration:**
  - สาธิตการให้ AI ช่วยร่างและแจ้งข้อควรระวัง
  - สาธิตการทำงานของ Legal Wording Reviewer
  - **ย้ำเตือน:** “AI เป็นเครื่องมือช่วยร่างและช่วยตรวจ ไม่ใช่ผู้วินิจฉัย ต้องตรวจสอบโดยนิติกร/กรรมการทุกครั้งก่อนนำไปใช้จริง”
- [ ] **Citation Coverage Demonstration:**
  - สาธิตการตรวจสอบมาตราอ้างอิง 
  - **ย้ำเตือน:** “ไม่มีแหล่งอ้างอิง = ไม่ควรใช้เป็นข้อกฎหมายหรือเหตุผลวินิจฉัย”
- [ ] **DOCX Export Demonstration:**
  - สาธิตการส่งออกไฟล์และตรวจสอบรูปแบบเอกสารใน Microsoft Word
- [ ] **Q&A:**
  - เปิดโอกาสให้ผู้เข้าร่วมอบรมซักถามข้อสงสัย
- [ ] **Post-Training Feedback:**
  - ให้ผู้เข้าร่วมกรอกแบบสอบถามความคิดเห็นตามแบบฟอร์ม (Pilot Feedback Form)
- [ ] **Security Awareness:**
  - ย้ำเตือน “ข้อมูลสำนวนเป็นข้อมูลราชการและอาจมีข้อมูลส่วนบุคคล ห้ามคัดลอก ส่งต่อ หรืออัปโหลดออกนอกระบบโดยไม่ได้รับอนุญาต”

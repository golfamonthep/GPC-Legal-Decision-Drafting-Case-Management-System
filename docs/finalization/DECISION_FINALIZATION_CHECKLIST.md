# Decision Finalization Checklist

When a case has passed a board meeting, follow this checklist to finalize the decision safely:

- [ ] **Meeting Result Recorded**: Ensure the board result (e.g. "เห็นชอบตามร่าง", "ให้แก้ไขร่าง") is accurately recorded in the Meeting Agenda panel.
- [ ] **Revision Instruction Reviewed**: If the board requested changes, review the instruction carefully.
- [ ] **Draft Revised**: Complete manual edits to the draft sections based on instructions. AI is strictly prohibited from auto-generating final text without review.
- [ ] **Wording Reviewed**: Conduct a final read-through of the drafted text.
- [ ] **Citations Reviewed**: Verify all legal references are accurate.
- [ ] **Data Quality Checked**: Resolve any outstanding Data Quality issues (Critical / High).
- [ ] **Red Case Number Recorded**: The Registry Officer issues and records the official Red Case Number in the system.
- [ ] **Final DOCX Exported**: Export the final "คำวินิจฉัยฉบับสมบูรณ์" DOCX file using the system export button.
- [ ] **Signed Document Linked**: Once signed by the committee, upload to SharePoint/OneDrive and link the URL back to the case.
- [ ] **Finalization Confirmed**: Authorized staff clicks "ยืนยันความสมบูรณ์".
- [ ] **Case Closed**: Mark the case as Closed.
- [ ] **Audit Log Verified**: Confirm that actions appear correctly in the Case Timeline.

# Dispatch and Court Follow-up Checklist

Use this checklist to ensure all steps are completed for the dispatch and post-decision court follow-up process.

## 1. Pre-Dispatch Verification
- [ ] Decision has been finalized.
- [ ] Signed document has been linked or uploaded.
- [ ] Dispatch workflow has been initialized in the system.

## 2. Notice Preparation & Dispatch
- [ ] Notice document prepared and verified.
- [ ] Dispatch method selected (e.g., Registered Mail, In-person).
- [ ] Tracking number and dispatch date recorded.
- [ ] "Dispatch" action confirmed in the system.

## 3. Acknowledgement Recording
- [ ] Acknowledgement receipt or system confirmation received.
- [ ] Date of acknowledgement recorded in the system.
- [ ] If acknowledgement date is before dispatch date, a valid reason has been documented.
- [ ] System successfully calculated the court filing deadline.

## 4. Court Deadline Monitoring
- [ ] Dashboard indicates no near-due deadlines or overdue items without action.
- [ ] If no court case is filed within the legal period, case marked as `NO_COURT_CASE_REPORTED`.

## 5. Litigation Tracking (If Case is Filed)
- [ ] Court filing recorded with Court Name and Case Number.
- [ ] Periodic court events (e.g., hearings, submissions) recorded.
- [ ] Final judgment date and summary recorded.
- [ ] Court follow-up explicitly marked as `COMPLETED` after final judgment.
- [ ] If judgment requires further action, a new internal workflow is initiated.

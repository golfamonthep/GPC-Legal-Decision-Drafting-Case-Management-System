# ฐานข้อมูลดิบการแต่งตั้งตำรวจ วาระ 2569

เก็บเอกสารสามแหล่งที่ผู้ใช้ส่งเพื่อเป็นฐานตรวจสอบงานวิเคราะห์

- `raw/` มีสำเนา PDF ที่คงไบต์จากต้นฉบับทุกประการ
- `sources.sqlite3` มีทะเบียนเอกสารและข้อมูล PDF ต้นฉบับในตาราง `source_documents` คอลัมน์ `raw_pdf`
- `manifest.json` บันทึกเส้นทางต้นฉบับ บทบาทเอกสาร จำนวนหน้า ขนาด และ SHA-256

แหล่งอาวุโสปัจจุบันใช้ `seniority_2569_round4_2026-08-07_CURRENT.pdf` เพียงไฟล์เดียว ชื่อไฟล์นี้เป็นชื่อสำหรับจัดเก็บ ไม่ใช่การแก้เนื้อหาเอกสาร ต้นฉบับที่ผู้ใช้ส่งไม่มีนามสกุลไฟล์ แต่ตรวจพบลายเซ็น PDF และอ่านโครงสร้าง PDF ได้

สถานะ ACTIVE_USER_PROVIDED หมายถึงเอกสารที่ผู้ใช้ส่งสำหรับฐานงานนี้ ไม่ใช่การรับรองข้อเท็จจริงทุกข้อความ สถานะเนื้อหายังเป็น NOT_YET_VERIFIED จนกว่าจะตรวจเอกสารรายหน้าและรายบุคคล ดัชนีหรือผลวิเคราะห์ต้องอ้างกลับ PDF ต้นทาง หากยืนยันไม่ได้ให้ระบุ UNRESOLVED_SOURCE_GAP

ยังไม่ได้สร้างตารางรายบุคคลหรือปรับ workbook จำนวนผู้ได้รับแต่งตั้งห้ามนำไปแทนจำนวนตำแหน่งว่างจริง

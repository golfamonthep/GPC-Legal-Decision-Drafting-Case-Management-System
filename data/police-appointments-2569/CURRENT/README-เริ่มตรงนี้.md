# ฐานข้อมูลรวมปัจจุบัน วาระ 2569

อัปเดต 9 ต.ค. 2569: ตรวจภาพและเทียบชื่อผู้เลื่อนระดับ 181/184 ราย เปลี่ยนลำดับจาก workbook 66 ราย อีก 3 รายอยู่นอกระดับที่ PDF ครอบคลุม แยกจำนวนผู้เหมาะสมและหน้าอ้างอิงครบสำหรับ 181 ราย ยังไม่มี source ตำแหน่งว่างจริง จึงไม่คำนวณโควตาหรือกลุ่มผู้ได้รับเลื่อน

เปิด workbook ใน 3-กฎและผลวิเคราะห์ปัจจุบัน มี 2 แท็บตามเดิม รายละเอียดหน้า PDF และสถานะอยู่ในแถวรายบุคคล ดู QA-SENIORITY-CROSSWALK.csv สำหรับผลเทียบทั้ง 184 ราย และ SENIORITY-ACCOUNTS.json สำหรับจำนวนแยกประเภทที่มีผู้ได้รับเลื่อน

ฐาน SQLite อยู่ ../current-database.sqlite3 รวมต้นฉบับ PDF รายการแต่งตั้ง 281 ราย ข้อความอาวุโส 63 หน้า ผลจับคู่ 181 ราย และแถว workbook ปัจจุบัน

ข้อมูลแต่งตั้งยังสืบทอดการตรวจจากฐานเดิม ไม่ได้ตรวจภาพแต่งตั้งซ้ำทั้งหมด การตรวจครั้งนี้ยืนยันชื่อและลำดับในบัญชีอาวุโส ไม่ใช่การถอดชื่ออาวุโสทั้งบัญชี

ใช้กฎล่าสุด Strict Source Isolation และ Seniority Override แหล่งอาวุโสเดียวคือ PDF ครั้งที่ 4 ต้นฉบับผู้ใช้ไม่ถูกแก้ไข สำรองก่อนอัปเดตอยู่ ../archive/before-seniority-update-2026-10-09
